## LLMWiki

This collection supports multiple products. Each directory under `products/` is an independent OKF bundle, with links interpreted from that bundle's root. Neither `docs/` nor `docs/products/` is itself a bundle.

* [Library](products/library/index.md) - General knowledge shared across subjects. No concepts have been added yet.
* [Web Essentials](products/web-essentials/index.md) - Build dynamic web pages primarily with native CSS Grid, Container Queries, :has(), Cascade Layers, and CSS custom properties before adding custom code.

Add named products as separate bundles at `products/<product-slug>/index.md` and list them here. Before adding knowledge, identify its owning product or explicitly assign it to Library.

The existing `articles/`, `comments/`, `images/`, `notes/`, and `tools/` directories and other files in `docs/` remain static documentation outside the wiki. They have not been submitted or imported as wiki knowledge. Leave them untouched during wiki maintenance unless a separate change is explicitly requested.
