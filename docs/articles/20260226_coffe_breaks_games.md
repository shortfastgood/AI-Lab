# Coffe Breaks Games

**35 years ago, during coffee breaks, we played games.** 

Today, during the same coffee break, we can build one.

At the start of my career as a developer, coffee breaks were when we tried out the latest games released by specialist software companies.

Now, we can imagine a game, ask AI to generate it, and still have time left to play it before the break is over.

These are still Minimum Viable Products (MVPs). They might lack sound effects or polish — but they work.

And that changes things.

AI-generated MVPs allow us to: • test ideas at extremely low cost • validate concepts quickly • interact with clients in a much more dynamic way • iterate before committing to full-scale development

What’s even more interesting is that the MVP code is often solid enough to become the foundation of the final product.

The shift from “writing everything from scratch” to “co-creating with AI” is real — but it’s also a journey that requires learning how to guide the tools properly.

If you’re curious, you can find concrete examples in my MVP lab on GitHub: https://github.com/shortfastgood/one-prompt-apps
