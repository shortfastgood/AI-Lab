# Web Essentials

Build dynamic web pages primarily with browser-native CSS features before adding custom code.

The product overview prioritizes:

* **CSS Grid** for two-dimensional page and component layouts.
* **Container Queries** for components that adapt to the size of their container.
* **`:has()`** for state and relationship-based styling within the CSS scope.
* **Cascade Layers** to organize style precedence and keep overrides predictable.
* **CSS custom properties** for reusable design tokens and runtime theme values.

## Concepts

* [Design Tokens and Architecture](design-tokens-and-architecture.md) - Design token organization and Cascade Layer precedence for maintainable pure-CSS pages.
* [Responsive Table Architecture](tables-architecture.md) - Static, table-specific Container Query profiles with AI-assisted authoring.
* [Responsive Table Specifications](tables-specs.md) - Requirements for predefined profiles, table-specific layouts, filtering, and paging.
